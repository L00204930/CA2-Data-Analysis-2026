CA2 Data Analysis 2026
Dataset
Top Movies: Ratings, Genres, Popularity & Metadata (Kaggle)

Project Overview
This project investigates factors influencing movie ratings and popularity using statistical analysis in RStudio.

Research Questions
Is there a significant relationship between movie popularity and average audience rating?

Do movie ratings differ significantly across genres?

Is there a significant relationship between the number of votes received and movie popularity?

Has the average movie rating changed over time?

Does movie popularity differ according to original language?

Statistical Tests Used
Spearman Rank Correlation
One-Way ANOVA
Simple Linear Regression
Kruskal-Wallis Test
